# SPAR — Project Page

Project website for **SPAR: Semantic-Pixel Self-Alignment and Adaptive Routing for Unified Multimodal Models**.

## Local preview

```bash
python3 -m http.server 8000
# open http://localhost:8000
```

## Files

- `index.html` — main page
- `styles.css` — styles (HKUST-themed palette)
- `main.js` — lightbox / copy-bibtex / nav interactions
- `figures/` — paper figures
- `assets/` — favicon

## Deploy (GitHub Pages)

This is the `website` branch. To serve it via GitHub Pages, set Pages source to this branch (root).
